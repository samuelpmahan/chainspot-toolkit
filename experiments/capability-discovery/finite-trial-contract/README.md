# Finite trial contract — opt-in pure checker

This module is an explicit-import engineering experiment, not a producer, loader, algorithm feature or permission to run a trial. Nothing imports it by default. There is no default-ON registration or production hook. It has no imports, I/O, codec, tokens, timers, store/PATH/query/CV/render entry or callback capability. Importing the module only defines functions/constants; callers explicitly supply ordinary in-memory literals.

The four runnable files are byte-exact E2032 core v2 and its three drivers. Source headers retain their construction-time E2028/E2030/UNEXECUTED wording for provenance; current execution authority is E2035 and independently accepted R2035, not those historical comments. Tests import only Node test/assert and the sibling core. No sample ledger is a required runtime dependency; tests contain their own fabricated fixtures.

## Six exports and exact scope

Each export catches its own contract rejection as `{status:'REFUSED',reason}`; pairedDiagnostic can instead surface a nested station rejection inside a HOLD witness. Result records below are projections or arithmetic, not authenticated evidence. Objects must have ordinary Object.prototype, exact enumerable own data keys and no undefined fields; arrays must be ordinary dense arrays with no extra keys. This is a trusted bounded-literal contract, not protection from hostile Proxies, mutation, replaced intrinsics or arbitrary thrown objects. It does not deep-freeze inputs or provide a security/resource sandbox.
