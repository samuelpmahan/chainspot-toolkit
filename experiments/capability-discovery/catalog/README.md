Callable addresses are module exports, not new registered FG addresses. recipes.json is a declarative experiment plan; it does not execute CV or change pipeline defaults.

Flow: validate source bytes and dependency/contracts, evaluate caller evidence gates, then select an explicitly declared recipe branch.
