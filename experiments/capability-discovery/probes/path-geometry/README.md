# Posthoc path geometry probe

`path-geometry.mjs` is a dependency-free ES module. It measures supplied polylines and never changes native routing, candidate matching or defaults.

`describePath({points, frame, width?, support?, pairedEdges?})` validates finite two-dimensional points and rejects fewer than two points, consecutive duplicates, invalid observations and overflow. The named frame is mandatory. Each supplied segment is a run: the descriptor performs no smoothing, collinear merging or inference of physical bends. It returns segment lengths in that frame's pixels, signed turns at every interior vertex, their positions and accumulated distances. Turn sign follows the caller's coordinate axes. A 180-degree reversal's sign is numerically ambiguous; its absolute angle is meaningful.

Optional `width` names provenance and supplies a positive full ribbon width or one width per segment. Normalized lengths use that same-image denominator; this supplies no meter scale. Optional `support` supplies one [0,1] value or null per vertex, a caller-chosen threshold and provenance. Output includes observed coverage and the supported fraction of observed samples. These are equally weighted input samples, not arc-length coverage or calibrated probabilities. Optional `pairedEdges` supplies left/right cross-section points or null per vertex, with provenance. Only those pairs permit midpoint offsets; heading or brightness alone never substitutes for paired edges. Edge association and width calibration remain caller testimony.

`countTurns(descriptor, {definition, predicate})` requires an explicit named caller definition and a boolean predicate. The fixture's example cutoff is illustrative, not learned or approved. There is no default sharp-turn count, exponential penalty, three-bend rule, score, ownership or human-acceptance state.

Run `node --test path-geometry.test.mjs`. Tests cover straight/six-turn discrimination, rigid-transform and scale invariance, local widths, paired-edge midpoint invariance, unknown support/edges, U-turns, unchanged collinear vertices, malformed/degenerate inputs and overflow. Run `node analyze-native.mjs /path/to/baseline-native.json /path/to/heading-native.json` for existing W2 receipts; it prints descriptors and exact input hashes without rerunning CV.

E103/R103 source evidence remains qualified: an independently reproduced scoring existence case ties 90px straight and 170px six-bend paths near1.6 with matching local orientation; an all-horizontal field with dense sampling instead scores straight1.6 versus bent approximately5.92e-17 at alignmentPower2. This is evidence of absent explicit bend prior, not universal immunity to bends. Neither result is computed by this descriptor. Source identities and review artifacts are recorded in result.json.
