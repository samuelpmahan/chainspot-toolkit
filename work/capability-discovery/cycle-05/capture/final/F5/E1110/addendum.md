## A3 — fully tagged reversible raw-value codec

Every value is recursively encoded as the exact tagged-array grammar in the JSON; no unescaped native object is mistaken for a codec tag. Native arrays/objects that resemble tags are themselves encoded as array/object nodes. Supported leaf values are null, booleans, strings, finite IEEE754 numbers, negative zero, NaN and both infinities. Supported containers are dense ordinary arrays, ordinary/null-prototype objects with own enumerable data properties, and exact Uint8Array instances (including native loss corridor arrays). Other typed constructors, Buffer subclasses, DataView, ArrayBuffer, errors, Maps/Sets, dates, functions, BigInt, symbols, undefined values/properties, sparse arrays, named array extras, accessors, unsupported prototypes and cycles are rejected. Missing object properties stay absent; explicit undefined is outside domain. Object property order and null-prototype kind are retained; property descriptor flags, shared-reference aliasing and backing-buffer offsets are not promised. Encode/decode is a value-tree contract.

Encode Uint8Array as constructor name, exact length and ordered validated bytes, not a flattened ordinary array or JSON numeric-property object. Encode all number exceptional cases before JSON.stringify. Finite non-negative-zero JSON number payloads roundtrip to the same IEEE754 number; negative zero has its own tag. Duplicate object property names, unsupported tags/arity, invalid typed constructors/lengths, malformed numeric tags and decoder resource overflows are errors. Decoder uses own data-property definition, including for `__proto__`, rather than unsafe assignment. Source public profile nulls remain null; stationContrast NaN remains tagged NaN; finite invalid contrasts stay finite with flag0.

The raw value file is UTF-8 `JSON.stringify(E(root)) + LF`; hash EXACT original file bytes. Do not use fg/canon plain/canonicalJson for raw results or sidecar. It remains unchanged for native key behavior. Store full native `{value,unit,emits}` before display transformation and complete instrumentation sidecar in separate hash-bound files. Timing-bearing sidecar hashes identify this execution's bytes only, not deterministic equality. Native corridor RGB is already source-rounded; codec cannot recover pre-rounded colors. No hash is cryptographic execution attestation.

Before any scientific producer is admitted, separately admitted non-CV roundtrip tests must demonstrate Object.is numeric preservation, null-vs-NaN, -0, infinities, ordinary tag-looking values, own `__proto__`, property order/null prototype, every rejected shape, both Uint8Array corridor examples and allHidden-style NaN/flag arrays.
