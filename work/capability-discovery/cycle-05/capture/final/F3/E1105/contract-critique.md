## Source contract traps to expose

| Public query | Retained public value and important seam |
| --- | --- |
| profile | `{value,unit}`; 241 offsets represented as `[first,last,step]`, profLum, okCount, stationsCount. NaN entries are deliberately converted to null by source. Empty stations return a condition, not a profile array. The profiler averages independently over visible samples at each normal offset. |
| edgePair | Recomputes profileAt internally; there is no public argument accepting the already retained profile. No pair returns `{condition:'no edge pair'}`, not lower-level null. This is an averaged-profile fit, not pointwise paired-edge evidence. The default support guard requires `ok >= max(8,.2*nT)` on enough offsets. |
| stationContrast | Plain arrays leftLum/rightLum/okLeft/okRight and stationsCount. NaN is not normalized by the public export. Each side's numerical contrast can remain finite while its ok flag is 0. Preserve it. Raw inside/outside means and unmasked sample counts are NOT exported. |
| loss | Source-produced rounded diagnostic summaries, stations.edgeMinLum, overlayFrac, gap summaries and typed corridor arrays. It internally calls stationContrastAt, samplesAt and overlayAt again; it is additional execution, not a view over the retained stationContrast result. Width<=0/no-station conditions are early-return executions. |

The q wrapper returns `{value:{schema:'nctk-s6-path@1',condition:...},unit:'condition'}` for missing/unrecognized raster. Its rasterOf check is only truthy rgba plus integer widthPx: it does not validate all dimensions, byte counts, masks, geometric arguments, steps or resource bounds. The comment that data conditions never throw is not a complete safety guarantee. arange with malformed/nonpositive steps or enormous ranges can throw or allocate excessively. Preflight is mandatory before invoking any query.

Loss uses raw `min(left,right)>tauLum` when both validity flags hold, but exposes rounded/min-collapsed values. Reconstructing threshold passes from rounded edgeMinLum can disagree near tau. Its default tau=8 is historical raw diagnostic behavior, not a new classifier or scientific threshold. Do not infer raw bilateral channels from loss. With profile:null and threshold:null, overlay remains explicitly a white-overlay brightness proxy; overlay pass/loss summaries and agreementCounts remain null. Do not fabricate alpha or threshold evidence. The source's gap length is sampled-station run count times step; it is not proof of physical occlusion length. Masked samples end runs without evidence either way.

## Proposed smallest input

Use a strict object-shaped input; unknown keys, sparse arrays and unsupported object/typed-array shapes are invalid before execution. Disabled absent/false enabled produces DISABLED with empty calls, without reading pixels, hashing source files or parsing a receipt. Enabled validation failure is UNKNOWN/NOT_EXECUTED with an explicit reason, not a claimed measurement refusal from source.

1. Named pixel frame; caller image ID; widthPx/heightPx safe positive integers; complete dense RGBA bytes; exact RGBA SHA256 and caller geometry-provenance text. Accept a small explicitly declared byte-container set and copy it. Alpha is retained unchanged, not muted/composited or interpreted as physical transparency. Record decoded-pixel identity separately from encoded-file hash and decoder testimony. Verify only hashes for bytes actually supplied.
2. Explicit mask:null or complete same-frame/same-size dense binary mask plus exact mask hash. Distinguish null from all-zero mask in input provenance. Apply no new dilation, clipping or mask construction. If adapting existing boxes, make that a separately explicit frozen transformation with its own provenance; do not silently assume Dev72 and JS masks are equivalent.
3. Unique comparison/station ID, finite originPx and phiRad, explicit t0Px/t1Px/stepPx. For the proposed long16 protocol freeze stepPx=1, arange count=16, t1Px=t0Px+16 and retain actual source counts. No automatic recentering, short-window generation, heading change or endpoint inference. A stationContrast array of length16 is already the longitudinally ordered bilateral observation; sixteen individually invoked queries are unnecessary and would have different execution accounting.
4. Explicit `{frame,scope:'LOCAL',valuesPx:[...]}` caller-supplied width bank, positive finite distinct values in declared order, and explicit nonnegative edge tolerance/lateral limit. Preserve an explicit empty bank; no implicit width search or fallback width. Preserve caller-supplied geometry, width and image identity as testimony; semantic identity/calibration remain UNKNOWN/null.
5. A predeclared practical resource envelope for raster pixels, mask bytes, station/comparison count, candidate count, sample count and width-dependent corridor allocation. Finite numbers alone are insufficient: samplesAt/loss allocates with `R=ceil(width)` and loops over width-dependent arrays. Validate safe arithmetic, no holes and representable nonempty station spacing before calls. Exact cap values require root/F6 agreement; no mathematical or physical validity follows from a cap. Do not invent unapproved resource constants in scientific interpretation.

## Call plan, counts and cache honesty

Proposed fixed plan per comparison: one public profile call; for each declared width, edgePair then stationContrast then loss, all with identical raster object, mask and declared pose/window. Retain exact effective args, including explicit loss `profile:null`, `threshold:null`, historical tauLum=8, default band `[1,3]`, along=2 and source constants/provenance. Do not invoke width, samples or overlayFraction separately unless the frozen plan says so. Do not supply options that the public query ignores (notably profile lat0 is not a stationContrast/loss shift).

For K comparisons and candidate-bank lengths B_i, actual intended API call count is `K + 3*sum(B_i)`. Every invocation has monotonically ordered ID, query name, effective args, start/completion/error state and the complete raw `{value,unit}` response. Count attempts, completed returns, exceptions, conditional responses, disabled/preflight abstentions and omitted-by-empty-bank stages separately. Any caught exception must leave a partial retained trace, never a completed-success claim. Disabled/preflight-invalid cases make zero API calls; an empty bank can still execute its profile call and has no width rows. This makes UNKNOWN-with-execution distinguishable from NOT_EXECUTED.

Source-derived internal work expectations per comparison are profileAt `1+B`, stationContrastAt `2B`, samplesAt/overlayAt/corridorOf `B` for successful positive-width nonempty-window loss calls. These are source-derived expectations, NOT measured counters. Every valid public q invocation calls ctxOf/lumOf; LUM is a WeakMap keyed by raster object identity. A fresh private immutable raster object avoids stale luminance from a mutated backing RGBA buffer; fresh object per run prevents cross-run LUM reuse. Hash RGBA and mask before/after; do not expose a mutable buffer to callers. Cache hit/computation counts remain UNKNOWN unless genuinely observed; an operation-label count is not an internal pixel-sampling count.

For default stationContrast each station schedules 5 along positions times 5 band offsets times inside/outside times two sides =100 attempted geometric sample positions. Their coordinates overlap, masked sites skip luminance reads, and mask reads are separate. The API exports only bilateral validity flags, not per-band unmasked counts or actual sampling counters. Retain these as unknown; do not turn 100 attempts or sixteen output rows into independent observations.

Call PATH_QUERIES directly if the scope is the standalone exported public API. This does NOT exercise registerQueries, Part resolution, a gateway, or its argument cache: record invocationMode='direct-export' and externalCache='NOT_USED'. The vendored closure contains only a comment about registerQueries caching, not the registry implementation. Do not claim a gateway cache key/invalidator was verified or repaired. If a registry route is later required, pin/read/verify its actual implementation and resolved Part content; that is an additional scoped contract review.

## Sound falsifiers (proposals, not observed outcomes)

- Fixed-raster positive plus two-/six-column gap controls: a finite averaged edge fit may coexist with lower/absent pointwise bilateral support. With along±2 smoothing, a two-column gap need not yield a failed central sample. Failure to detect every narrow gap is not a serialization bug or proof of continuity.
- Bright organic control: matching/favorable raw channels must retain semantic identity UNKNOWN; a positive is a semantic counterexample, not a newly accepted detector.
- Offset control: compare unchanged caller pose, not a recentered rerun. Fit midpoint and bilateral contrasts have different windows/normal reference and need not agree.
- All-masked/partial masks: keep NaN, flags, profile counts and no-pair conditions; a finite invalid contrast is retained but not positive bilateral evidence. Fully masked loss may have visibleCount0, null fractions and longestGap0; zero gap is not zero physical loss.
- Short-window guard control: public edgePair null/condition for nT<8 under default minOk is structural, not evidence of absent physical edges. Long16 observations do not remove this limitation from separately retained short profiles.
- Serializer control with NaN/infinities/negative-zero/null and typed corridor arrays: decode(encode(raw)) preserves the promised raw distinctions. Renderer must show the same retained samples without invoking CV.
- Integrity/execution controls: tampered raster/mask/source/trace bytes fail before reuse; unchanged source hashes stay pinned; invocation logs account for every requested query including conditions/noops/abstentions. Shared-pixel repetitions and direct-vs-cache repeats do not increase independent confidence.

These controls can falsify wrapper behavior and overly strong continuity/identity interpretations. They cannot prove physical edge identity, calibrated uncertainty, meter scale, independent confidence, real-course accuracy, protocol blindness, human acceptance, or permission to promote a default.
