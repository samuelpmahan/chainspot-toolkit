## Confirmed design reuse and required precision

1. **Only bounded tagged targets, not whole aggregate decode.** Pinned codec exports lowercase `decodeValue`, `decodeBytes`, `encodeValue`, `encodeBytes`; `SmallDecode` is a new helper guard, not a codec API. `decodeValue` enforces semantic depth/node/typed budgets but does **not** enforce `maxBytes` on its existing encoded tree. Before `decodeValue`, SmallDecode must explicitly serialize the selected tagged subtree in canonical JSON+LF, UTF8-byte bound it at32768, and independently count/validate its grammar; then call the pinned decoder with maxNodes8192 and semantic maxDepth<=32. Never pass `maxDepth:40` to the codec (hard limit32). Encoded-tree depth40 is a distinct proposed outer traversal guard. Budgeting a JSON string is not budgeting only its character count.
2. **Exact native grammar is narrower than generic codec grammar.** Require `['object','plain',pairs]` for source-native objects; the codec also supports null-prototype objects, which must not silently pass the source predicate. Reject duplicate/missing/extra keys, wrong node arity/tags, unsupported constructors/prototypes, non-dense arrays and wrong primitive types. A malformed/null/string pair field is fatal, whereas an exact seven-number pair with nonfinite values/nonpositive width is the predeclared numeric-unusable skip. stationContrast luminance is number-typed (finite/NaN retained), not null; flags are numeric0/1, arrays ordinary/dense. Do not normalize null/NaN/-0, round fit values, add refined nominal-width/center cutoffs or infer eligibility from displayed tokens.
3. **Canonical fragment equivalence means exact bytes.** For each selected encoded subtree, `UTF8(JSON.stringify(encodedSubtree)+'\n')` must equal the prehashed bound fragment bytes including exactly the LF. Do not call `encodeValue` on the already-tagged tree (double encoding), trim whitespace, sort object pair order, normalize numbers or compare parsed values only. Aggregate-root shape and exact fixed paths must be validated before indexing; no recursive find-by-field-name/value can substitute for a fixed structural path.
4. **Correct paths and joins.** The value-trace file encodes the trace root itself, not `{valueTrace:...}`. `.plannedQueries[i]` contains query/rawArgs/declaration identity but no state/error. `.queryTrace[i]` contains state/error/nativeAnswer; require COMPLETED/error exactly null after binding fit and control. `.inputIntegrity.snapshots[].checks[]` contains planIndex/post/verified, no error field. A callback root is `{comparisonId,captureIndex,nativeEntry}`; status/error live at `.nativeEntry.status/.error`. Callbacks carry **no args/rawArgs**. Do not normalize absent fields or claim independent dynamic argument capture. Attribution is pinned-source-derived joining, not authentication of executed code.
5. **Prehash176, then bounded selection.** Source fixed160 produces11 callbacks per comparison: global callback filename `K=11*c+captureIndex`, not local seq. Constant capture0/seq1/parent0/depth1 exits before profile capture1/seq0/parentnull/depth0. For fit/control plan-local indices1/2,4/5,7/8, query seq and capture are2/3,5/6,8/9. Prehash all176 callback fragments with their manifest bindings; subsequently select96 fit/control callbacks and16 constant/profile context pairs (32 callback nodes). Other48 loss callbacks are prehashed but need not be native-decoded. This does not require profile answer fragments (their max body size exceeds8192); no widening answer selection merely to reconstruct context.
6. **Default OFF, no writes, closed inputs.** Preserve exactly own enumerable data request fields schema/enabled/token, no arbitrary root/geometry/evidence/codec/cap/output injection. Missing/inherited/false own enabled returns DISABLED before evidence/source I/O, dynamic codec import, token/output work or unrelated getters. An enabled accessor/nonboolean rejects without invocation/coercion. Node builtins and the helper-under-test plus pinned pure codec are the entire proposed test import surface; no recipe/PATH/store/image module imports. Reading source22 bodies as bytes for hashes is allowed future verification, not importing them. Exact token string is an admission identifier only: helper writes NO files and provides no durable spent-token or exclusive output reservation. A future external admitted runner must supply those controls before a later enabled packet; don't claim this helper does.
7. **Regular descriptors do not establish no-symlink ancestors.** Specify and test leaf **and every ancestor** from the fixed workspace/raw/source roots: reject symlink components, traversal, alternate root/remap and unexpected source22 paths. `O_NOFOLLOW` protects only a final component, not an ancestor; O_NONBLOCK prevents waiting on FIFO but does not make a descriptor regular. Use lstat/realpath containment plus leaf open flags, fstat regular/exact size, bounded reads, EOF/length checks, hash BEFORE parse/decode/import, and close in finally. Bind descriptor/path identity as appropriate and retain source/postcheck mismatch. No claim these ordinary host checks defeat adversarial concurrent replacement or authenticate ESM execution. Old bounded reader is an example of regular/O_NONBLOCK/size/EOF/hash checks, not an existing ancestor-symlink implementation.

Query callback and returned-answer computed emissions must be checked separately from `nativeEntry.cached`: the store's PATH outParts[] keeps its result-cache key null/cached false even when registerQueries' answer Map could return cached emits. Do not impose query computed emissions on the constant callback; preserve and validate each source-derived native event shape rather than manufacturing missing fields.

## Proposed counterexamples — all UNEXECUTED

1. SmallDecode passes `maxBytes:32768` only to decodeValue and receives a larger existing tree: decoder itself cannot enforce that byte cap. Explicit subtree UTF8 byte guard must reject first.
2. Encoded native object uses `null-prototype`, or duplicate plain-object pair names: generic codec acceptance must not bypass exact source-native grammar.
3. Parsed nativeAnswer is value-equal but wire has missing LF/extra space/reordered pairs; exact fragment-byte comparison rejects it. Double-encoding a tagged node fails rather than silently comparing altered wire.
4. QueryTrace check accidentally reads plannedQueries.state or callback.args; fail on the wrong path, never normalize absent fields or claim dynamic captured args.
5. Fragment K is taken as local seq/capture. The constant/profile reversal and global11*c offset must expose incorrect joins; no out-of-selection profile answer read to compensate.
6. Two full verification passes fit8MiB but a third is triggered by an unbudgeted postcheck: pre-read guard stops before excess, no raising cap/retry. Expanded v2 protocol is measured/rebound prospectively.
7. Leaf file is ordinary under a symlinked parent/source ancestor; O_NOFOLLOW alone does not catch this. Guard must reject ancestor substitution before bytes/import.
8. Disabled request has throwing unrelated getter or supplied arbitrary root; zero I/O/no getter reads and closed-shape refusal on enabled request. Consumed admission token does not magically become externally spent state inside a no-write helper.
9. Encoded tree uses many typed payload atoms or deep object/pair layers: JSON tree counter/depth40 differs from native codec node/depth32 accounting. Never declare sufficiency from the latter.
10. Exact48 output duplicates large original request/source metadata per slot or embeds encoded bytes in its own encoded plan:2MiB can fail; freeze the schema/proof before exposure, not prune after failure.
