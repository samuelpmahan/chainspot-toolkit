# Agent references (progressive disclosure)

Start with `AGENTS.md` at the repo root. Open a page here only when the task needs it:
`node scripts/pxc.mjs explain <topic>` prints it.

| topic | open it when you are about to... |
|---|---|
| `prototyping` | try an idea quickly, or graduate a working prototype into the system |
| `boundary` | write pixel math, or add a question the store should answer |
| `parts` | read inputs, produce an output, name an address, or make something render |
| `calculations` | add a step that computes something, or measure what it does |
| `fg` | add a check or property to a stage's FunctionalGuarantee |
| `evidence` | report a result, render it, judge it, or claim a constant |
| `lanes` | work as the platform lane or the algorithm lane, or start the algorithm lane |
